## A. 中西時辰八字（含真太陽時校正）

輸入：公曆日期時間（北京時間 UTC+8）、出生地經度 lon（東經為正，西經為負）。
1. 平太陽時 = 北京時間 + (lon − 120) × 4 分鐘。
2. 均時差 EoT（分鐘），N = 當年第幾天（1 月 1 日 = 1）：
   B = 2π × (N − 81) / 364
   EoT = 9.87 × sin(2B) − 7.53 × cos(B) − 1.5 × sin(B)
3. 真太陽時 = 平太陽時 + EoT。真太陽時跨日時，日柱跟着跨日（以真太陽時的日期起日柱）。
4. 時辰 = floor(((真太陽時小時 + 1) % 24) / 2)；23:00 起算子時，歸次日（與 v1 一致）。
5. 時柱天干（五鼠遁）：日干 甲己→子時起甲子；乙庚→丙子；丙辛→戊子；丁壬→庚子；戊癸→壬子。即 時干序 = ((日干序 % 5) × 2 + 時支序) % 10。
6. 月柱天干（五虎遁）：年干 甲己→正月丙寅；乙庚→戊寅；丙辛→庚寅；丁壬→壬寅；戊癸→甲寅。即 寅月干序 = ((年干序 % 5) × 2 + 2) % 10，之後按節氣月順推。
7. 「中西時辰」顯示：西式時間（北京時間、真太陽時 HH:MM）+ 中式時辰名（子時…亥時）+ 初/中/末（見 F）。
8. 顯示四柱八字：年柱、月柱、日柱、時柱（含納音）。未選出生地時，預設經度 120（不校正）並提示。
9. 驗收：寧波（121.55°E）1980-06-06 12:00 → 平太陽時 12:06，EoT ≈ +1.3 分 → 真太陽時約 12:08，仍為午時。
   烏魯木齊（87.6°E）2000-01-01 12:00 → 平太陽時 09:50，EoT ≈ −3.6 分 → 約 09:47，巳時（未校正為午時）。
   出生地經度表：中國地級市＋港澳台＋常見海外城市，城市名繁體顯示，可手填經度。

## C. 佩戴物（幸運物）

- 規則：佩戴與自己三合、六合的生肖（原文：「通常用六合，也有一起來的做法」）。顯示：首選＝六合生肖；加碼＝兩個三合生肖。
- 禁忌：辰、午、酉、亥（龍、馬、雞、豬）自刑，**不要戴自己屬相**；其餘八個屬相戴自己屬相「沒害也沒好處」。
- 材質文案照原文：「傳統就是紅色繩子搭配玉的小玩物就可以了……你愛買 Cartier 都可以。」
- 例：屬馬 → 首選羊（六合），加碼虎、狗（三合）；不戴馬。屬豬 → 首選虎，加碼兔、羊；不戴豬。
- 來源：src-taisui.txt 第 419–522 行。

### E1. 八敗【通行版】（年支 + 農曆月）
口訣：「正月蛇，洞中休；二月老鼠餓昏頭；三月老牛遍地走；四月兔；五月豬；六月猴；七月狗；八月馬；九月羊；十月病虎滿山吼；十一曉雞架上愁；臘月老龍海底遊。」
表（農曆月 → 犯八敗的生肖）：正蛇、二鼠、三牛、四兔、五豬、六猴、七狗、八馬、九羊、十虎、十一雞、十二龍。
- 判定：生肖 == 表[農曆月] → 犯八敗，否則不犯。
- 原文斷語：「犯八敗的俗稱喪門星，男敗女家，女敗男家。」

## F. 時辰初、中、末

- 每個時辰 120 分鐘，分三段各 40 分鐘：初＝起點起 0–39 分，中＝40–79 分，末＝80–119 分。子時起點 23:00，丑時 01:00，依此類推。用真太陽時。

## G. 九星值年（行年九曜）【通勝】

《通勝錦囊》第 9–10 頁（PDF 第 12–13 頁）。按**虛歲 + 性別**取當年值年星，非按出生年。
- 虛歲 = 查詢年 − 年柱年 + 1（查詢年預設 2026 丙午年）。
- k = 虛歲 % 9（0 視為 9）。
- 男命：1 羅睺、2 土星、3 水星、4 金星、5 太陽、6 火星、7 計都、8 太陰、9 木星。
- 女命：1 計都、2 火星、3 木星、4 太陰、5 土星、6 羅睺、7 太陽、8 金星、9 水星。
- 驗證（原書歲數表）：男太陽值年 14、23、32…95 歲；女太陽 16、25…97 歲；男羅睺 10、19…；女計都 10、19…（逐表核對無誤）。

各星原文（右至左豎排轉錄；「□」為無法辨認）：

1. **羅睺**：行年值羅睺，主人百事憂。男子官災至，女人也憂愁。名曰口舌星，主見官非口舌，眼目之疾，女人見血光產厄之災，凡事不如意。每月初八日下界，用黃紙牌位寫天宮神首羅睺星君，燈九盞，正北祭之大吉。
2. **土星**：行年值土星，災事來相侵。出入多不順，提防小人心。名曰厄星，此年見災不安，家畜不旺，不利遠行，防小人暗害，宅不寧，夜多怪夢。每月十九日下界，用黃紙牌位寫中央戊己土德星君，燈五盞，正西祭之大吉。
3. **水星**：行年值水星，財喜主重興。男子福祿至，女子口舌侵。名曰福祿星，大人見喜，遠行有財，添人口；女子不利，多災難，不宜渡河。每月二十一日下界，用黑紙牌位寫北方壬癸水德星君，燈七盞，北方祭之大吉。
4. **金星**：行年值金星，凡事不遂心。男子憂災厄，大忌是女人。名曰□陽星【待核：疑「朝陽」】，貴人見喜，添人進口，婚姻嫁娶，恐有肚腹之災，出入提防小人。每月十五日下界，用白紙牌位寫西方庚辛金德星君，燈八盞，正西祭之大吉。
5. **太陽**：行年值太陽，終歲得安康。男子重重喜，女人有災殃。名曰太陽星，光輝天下，無處不明朗，主進行有財，大人見添人進口，萬事和合，女子不容此星，宜向東方吉。每月二十七日下界，用黃紙牌位寫日宮太陽天子星君，燈十二盞，向東祭之大吉。
6. **火星**：行年值火星，守舊且安身。男命不離刑【待核：「離」字】，女人多災難。名曰災星，主瘡疾，女人產難血光，男子官災，不利人口，不安六畜，不旺，自宜謹慎。每月二十九日下界，用紙牌位寫南方丙丁火德星君，燈十五盞，正南祭之大吉。
7. **計都**：行年值計都，災害不時無。陰人防口舌，猶可是丈夫。名曰凶星，大人不喜，六畜不利，陰人主口舌，遠行有財，在家防暗昧不明之患。每月十八日下降，用黃紙寫天宮分司計都星君，燈二十一盞，正西祭之大吉。
8. **太陰**：行年值太陰，諸事遂其心。前程宜遠行，求名並求利。名曰太陰星，宜見官有理，男子出入凡事遂心，女人有疾厄產患之難，宜禳解則吉。每月二十六日下界，用黃紙牌位寫月宮太陰皇后星君，燈七盞，正西祭之大吉。
9. **木星**：行年值木星，不利是陰人。發見微小疾，來為歲月遲【待核】。名曰福□星，其年男子有□目之疾，女人有血光之災，不妨婚姻和合，人口平安。每月二十五日下界，用青紙牌位寫東方甲乙木德星君，燈二十盞，東方祭之大吉。

總詩（照錄）：「此星入命喜燃燈，保汝平安福壽增。男女行年宜解祭，九星下降要虔誠。」
總說（照錄）：「凡人生命行年值某位星君，按後開下界日期虔誠齋戒燃燈祭之。士人加官進祿，商賈利增百倍，婦人遇吉星祭之求子得子，遇凶祭之可免災厄也。」

## J. 解鎖方案（不用郵件、不用後端，純前端可做）

目標：捐 10.01 元給林叔 → 林叔發一組「生辰綁定解鎖碼」→ 用戶在頁面輸入 → 完整版在頁面展開，並可「存成長圖 / 列印成 PDF」自己保存（取代發郵件）。

1. 完整版的斷語資料（part2 與 v1 的長文）在建置時用 AES-GCM 加密成一段密文嵌入頁面；明文不進倉庫的公開檔（金鑰與明文放在不公開的本地資料夾，建置腳本產出密文）。
2. 主金鑰 K：80 bit 隨機數，由林叔保管。
3. 生辰鍵 B = 「公曆日期 + 時辰 + 性別」字串，例 "1980-06-06|午|男"。
4. 解鎖碼 = Base32( K XOR SHA-256(B) 前 80 bit )，共 16 字，顯示為 XXXX-XXXX-XXXX-XXXX。
5. 前端解鎖：K = Base32解碼(碼) XOR SHA-256(B)；用 K（經 HKDF/SHA-256 擴成 256 bit）解密密文；GCM 驗證失敗即「碼不對或生辰不對」。全部用 WebCrypto，離線可用。
6. 好處：碼只對該生辰有效，轉給別人沒用；不需伺服器、不存任何個資。限制（要在說明裏老實寫）：懂技術的人能從自己的碼反推出 K，屬「君子鎖」，對 10.01 元的定位夠用；要防就定期換 K 重發。
7. 林叔發碼工具：另做一個不公開的本地小頁 / node 腳本（輸入生辰 → 輸出碼），不放進公開倉庫。
8. 頁面文案：「捐 10.01 元並把轉帳截圖和你的生辰發給林叔，林叔回你一組解鎖碼。輸入即可看完整版，可存長圖或 PDF。」（收款方式由林叔提供，前端只放一張收款碼圖片的位置。）
