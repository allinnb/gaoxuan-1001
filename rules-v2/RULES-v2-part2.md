# 搞玄@壹仟零壹夜 — 计算规则 v2 第二部分（RULES-v2-part2）

本文件补充 src/RULES.md（第0节通用基础照用：BR/ST 序、年柱以立春为界、月柱地支以节为界、日柱、纳音、时辰）。不重复：称骨、骨格、禽兽、田猪牛产、学堂、手艺、衣禄、看你怎死、二十八宿、黄帝四季、青龙白虎、太岁。

约定：
- 原文照录（保留原站错字/异体，必要处在"注"里说明）；【待核】= 无法从来源确认的单元格或用法，开发时显示"民间说法，查法存疑"之类提示即可，不要自行编造。
- 时辰初/中/末：一个时辰120分钟三等分。子时 23:00–00:59：初=23:00–23:39，中=23:40–00:19，末=00:20–00:59；丑时 01:00–02:59：初 01:00–01:39，中 01:40–02:19，末 02:20–02:59；其余以此类推（时辰起点 = 23:00 + 2h×index）。公式：offset = (分钟数自 23:00 起算) mod 120；part = floor(offset/40)，0初 1中 2末。
- 长生十二宫起点（同 RULES 第7节④）：金→巳，木→亥，水→申，火→寅，土→申；序 长生 沐浴 冠带 临官 帝旺 衰 病 死 墓 绝 胎 养。
- "月支"若无特别说明 = 月柱地支（节气月）；"农历月" = 农历月份数字 1..12（闰月按本月）。

## 2. 从年支说命（12生肖 · 北斗七星司命）
- 输入：年支（立春为界）。查表：12 条，key = 年支。
- 来源：《十二生肖三世相法之北斗七星》"北斗七星分十二宫坐生年命运休咎" https://m.xzw.com/shengxiao/zonghe/2011/0702/7737.html （子–巳）及 7737_2.html（午–亥）。繁体原文照录。
- 佐证：aqioo 110613（三世书批命样例）"查最宜供奉之神佛：所属北斗七星司令：武曲,巳生人属武曲星，寿注泰山桃树下…"与本表巳条逐字一致；另一样例（乙未年）"未生人属武曲星，寿注泰山粟树下，生身带羊刃…"与本表未条一致。
- 注【待核】：本表星名分配与通行"子贪狼、丑亥巨门、寅戌禄存、卯酉文曲、辰申廉贞、巳未武曲、午破军"不同（本表 寅=廉贞、卯=武曲、戌=禄存）。照原文显示，可加注"此为三世相流传版本"。

**子（貪狼）** 子年(鼠年)生人屬貪狼星，壽注泰山李樹下，生身帶木星，青帝之子（伏羲）。料米一石三斗，銅錢七十五文，為人心聰明，一生心驚，除宜齋戒外，須奉佛神保吉。

**丑（巨門）** 丑年(牛年)生人屬巨門星，壽注泰山杏樹下，生身帶土星，赤帝之子（神農）。料麻油一石七斗，銅錢一百文，為人一生多是非，性硬，主有宿疾，須奉祖佛方吉。

**寅（廉貞）** 寅年(虎年)生人屬廉貞星，壽注泰山松樹下，生身帶火星，白帝之子（夏禹）。料米二石五斗，銅錢五十文，為人一生心性急、聰明，出外與人不順、主有驚危、水厄之疾，宜奉金甲神（韋陀）方吉。

**卯（武曲）** 卯年(兔年)生人屬武曲星，壽注泰山梅樹下，生身帶金星，黃帝之子（軒轅）。料粟米一石一斗，金錢四十千文，為人聰明，老年享福，五福守命，富貴榮華，可奉觀音保吉。

**辰（廉貞）** 辰年(龍年)生人屬廉貞星，壽注泰山松樹下，生身帶木星，青帝之子（伏羲）。料米麻八斗二升，金錢十文，為人多計較，向公門得橫財，逢春吉，但主有血光之疾，宜奉金甲神保祐。（韋陀）

**巳（武曲）** 巳年(蛇年)生人屬武曲星，壽注泰山桃樹下，生身帶金星，黃帝之子（軒轅）。料大豆一石五斗，粟米二斤，銀錢四十文，為人聰明，好樂道術為業，主厄疾壓身，宜奉金甲神保吉。（韋陀）

**午（破軍）** 午年(馬年)生人屬破軍星，壽注泰山李樹下，生身帶金星，赤帝之子（神農）。料穀二石八斗二升，大豆二升，鐵錢九文，為人性善近貴，宜學術，主有三分氣疾，宜奉觀音保吉。

**未（武曲）** 未年(羊年)生人屬武曲星，壽注泰山粟樹下，生身帶羊刃，白帝之子（夏禹）。料小麥三斗二升，粟米三升一合，銅錢十八文，為人主有刀斧壓身，宜奉當天，燒夜香保吉。

**申（廉貞）** 申年(猴年)生人屬廉貞星，壽注泰山梨樹下，生身帶孛星，白帝之子（夏禹）。料油麻五石二升，銅錢一百文，為人性快很巧，得十方衣祿，有壽，但主有小災，宜供奉佛道。

**酉（文曲）** 酉年(雞年)生人屬文曲星，壽注泰山松樹下，生身帶水羅，黑帝之子（成湯）。料油麻一石七斗二升，銅錢十五文，為人衣祿不虧，但有刀斧之災，宜奉佛道吉。

**戌（祿存）** 戌年(狗年)生人屬祿存星，壽注泰山杏樹下，生身帶金星，白帝之子（夏禹）。料米二石三升，銅錢八十二貫，為人性急，宜出路求經，主小疾壓身，宜奉三聖帝君（關帝）方吉。

**亥（巨門）** 亥年(豬年)生人屬巨門星，壽注泰山梅樹下，生身帶土星，黃帝之子（軒轅）。料粟二石三斗，銅錢十貫，為人性高，初年平平，末限發達，榮華，宜奉觀音吉。

## 3. 从月份说命（十二月生人例）
- 输入：农历月 1..12（闰月按本月）。来源：https://www.aqioo.com/sanshishu/110855.html （12条完整；与 heyix 转载一致）。
- 注：原文"子月"=十一月，"腊月"=十二月；"命肉关"照录。另一版本见《三世相》识典古籍（九月"妻子刑"、冬月"鼠年牛地"等字异），不采用。

- 正月生人驿马临，早年必定显功名，文武遇此标金榜，庶民逢此有银金。
- 二月生人志多刚，怜贫爱老知仁义，口虽无毒事无常，运行好处有家计。
- 三月生人遇寿星，为人慈善更聪明，逢猪遇鼠兴家业，衣禄安然兴福祯。
- 四月生人志气高，运行旺地显名超，逢牛遇鼠添田地，衣禄财多万最滔。
- 五月生人心性宽，妻荣子贵在中年，命中受破刑冲患，管取名利得双全。
- 六月生人心性良，为人口快又高强，文臣遇此君堂位，庶士逢之主寿长。
- 七月生人命肉关，财源成败在中间，时逢子午清高贵，欲取功名甚不难。
- 八月生人志气美，庶民遇此好根基，早年得力功名达，一生财禄见光辉。
- 九月生人妻子伤，纵有兄弟各分张，运行犬鼠加官爵，蛇羊马地见灾殃。
- 十月生人品貌奇，妻荣子贵好根基，若遇运行龙虎地，腰金衣紫称丹樨。
- 子月生人何在闲，时逢子午必为官，常人遇此财丰足，鼠羊牛地置田庄。
- 腊月生人不受贫，初年必定显功名，白手成家自立业，勇猛刚强不让人。

## 4. 从时辰说命（十二时辰 · 星入命）
- 输入：时辰地支。来源：《三世书贵贱论》https://www.aqioo.com/sanshishu/110846.html 每时辰的"X时生人："总论句（12条完整）。
- 注：原文"上刻/中刻/末刻(下刻/尾刻)"可与第5节的初/中/末对应高亮（上=初、中=中、末=末，【待核】原文未明说等同）。"贵无星""人马元星""阎王星入命带型克"照录。

- 子时生人：玉皇星入命,上刻居官，中刻招财，末刻白手成家，可食四方财，财禄双全。
- 丑时生人：丑时生人阎王星入命带型克，上刻为人忠直，有权威，中刻主初年一成一败，末刻主三事退则吉。
- 寅时生人：为白帝星入命，能自创乾坤之造，上刻人才出众，中刻白手成家，下刻九流术士。逢之福禄双全。
- 卯时生人：贵无星入命，上刻人居宜显贵，中刻为出祖入舍，下刻为九流术士，过房离祖吉。
- 辰时生人：人马元星入命，命中带三刑六害，一生衣禄足用，宜三事迟则吉。上刻食四方禄，中刻人高傲，末刻离祖则吉并过房。
- 巳时生人：禄元星入命，上刻显耀门闾，名扬四海，中刻金榜上人，末刻为人贫穷。
- 午时生人：太阳星入命，上刻祖业难招，白手成家，为人忠直，不在人下，初年未遂，中刻六亲淡泊，衣食足用，下刻出入公堂必生贵子。
- 未时生人：太阴星入命，初年财来财去，上刻妻金石，子迟招，富贵双全，中刻人头好尾好，末刻人男女皆贵，只是氏孤灯独守。
- 申时生人：海角星入命，乃贵人不临之地，刑克六亲，初刻登高地，中刻为平常之人，末刻妻重迭，三事迟则吉。
- 酉时生人：为人忠直好乐，酉时初中得四方财，若是末刻则四海为家大吉昌。
- 戌时生人：为地母星，上刻作事有权柄，中刻祖业难招，尾刻财禄俱空。
- 亥时生人：亥时天父星，离祖成家，于妻硬对，子迟，上刻富贵双全，中刻大吉，下刻平常之人。

## 5. 从时辰初中末说命（36条）
- 输入：时辰地支 + 初/中/末（见文首定义）。来源：《三世书以生时看人命及六亲》https://www.aqioo.com/sanshishu/110724.html （36条完整，诗 + 解说）。繁简混排原样照录（"為""剋"）。
- 另一版本：110846 同页"子时初：…"等36条（贵贱论版），可作"另一说"。

**子时初**　诗：值此运如何，作事进退多，初年财未至，末限足财宝。  
解：先剋母，為人性急，头妻难招，长子有剋，六亲冷淡，兄弟不和，作事进退，初年不济，末限好，宜手艺行业吉。

**子时中**　诗：衣禄自然有，一生人近贵，為官作宰相，富贵大家声。  
解：父母在，為人一生快乐清闲，衣禄不亏，兄弟有分，子息可招，六亲大旺，不能受祖业，出外主有大财。

**子时末**　诗：生逢子时末，初年运未通，六亲无倚靠，兄弟两西东。  
解：先剋父，為人性宽，六亲兄弟无力，子息两硬，初年辛苦，作事有头无尾，主离祖过房，重拜爹娘之命。

**丑时初**　诗：生逢初丑时，衣禄积有餘，為人官职分，田產福人居。  
解：父母双全，二十前无刑剋，二十后进田庄，文武皆通，為人近贵，可有头目之分，六亲得力，兄弟有权，子息好。

**丑时中**　诗：生来发达迟，為人最辛苦，财禄随时进，逢喜又逢吉。  
解：先剋父，衣禄平平，為人必公道，早年辛苦，末运好，三十八后发财，兄弟难為，六亲冷淡，离祖可白手兴家。

**丑时末**　诗：為人丑时末，一生好风光，财来无剋破，学术手艺成。  
解：先剋母，為人辛苦，一生大事成，六亲兄弟无力，子息得力，衣禄中平，初年辛苦，四十后发财，末限胜前。

**寅时初**　诗：生来遇大耗，二女成双破，床头十文钱，床尾鬼来叫。  
解：先剋父，為人近贵，凶事成吉，初年不佳，三十年奔波，三十七岁后好，六亲冷淡，兄弟清疏，子息不亏，有子送老。

**寅时中**　诗：宅舍好风光，生来大吉祥，一生多快乐，把笔作文章。  
解：父母双全，三十年不剋，為人作事有权柄，衣禄不亏，六亲有分，兄弟施為，子息二三，為人有志气，大吉之命。

**寅时末**　诗：寅时末事多，身安心不安，一生多疾厄，小艇江上漂。  
解：先剋母，六亲无力，头夫或妻、头子难招，兄弟不和，初年辛苦，三十六岁发财，末限胜前，衣禄平平，作事进退。

**卯时初**　诗：生来卯时初，為人最辛苦，衣禄随时度，逢喜又逢悲。  
解：先剋母，為人作事有始无终，兄弟少力，六亲冷淡，宜离祖过房，初年奔波，刑剋三夫或妻，子息半真假送老。

**卯时中**　诗：住居大高堂，兄弟有主张，一生受富足，文武近君王。  
解：父母双全，三十年父母在，男人為官，女人有福，一生近贵，女人益夫，文武通，六亲兄弟有力，子息不亏，衣禄有餘。

**卯时末**　诗：时末走途东，辛苦家庭好，无灾时运至，财禄积门庭。  
解：先剋父，作事本分忠厚，初年有晦气奔波，离祖过房，自整门风，六亲冷淡，兄弟少力，末限胜前。

**辰时初**　诗：衣禄自然来，兄弟六亲小，父母须刑剋，末限更无忧。  
解：父母在，為人性急，六亲少力，子难招，兄弟不和，心急，大事成小，宜手艺营生，初限平平，四十二岁后渐好，衣禄有餘。

**辰时中**　诗：衣禄得人抬，先忧后吉来，六亲虽冷淡，末限足钱财。  
解：先剋父，為人心行公道，性急，一生近贵，出入有贵人扶持，离祖成家，六亲兄弟难為，初年不济，奔波，末限胜前。

**辰时末**　诗：衣禄自然有，朱紫作朝郎，一朝命发达，富贵有名声。  
解：先剋母，為人聪明，衣禄足用，大有声名，六亲大旺，兄分有力，為官头目之分，女命益夫，一生富贵食禄好。

**巳时初**　诗：宅舍好风光，宜早学文章，女命有权柄，男女似花香。  
解：先剋母，為人衣禄足，六亲小力，兄弟难為，长子难招，头夫或妻有剋，初年奔波，末限大利，女命益夫，一生衣禄好。

**巳时中**　诗：时中无剋破，一生积钱财，因公得财物，出外好生涯。  
解：父母俱全，一生近贵，财禄足用，兄弟有分，子息和顺，作朝郎，师术，头目之分，大事成小，慷慨之命。

**巳时末**　诗：要行千里路，心急马行迟，红日如天火，行到不能為。  
解：先剋父，為人近贵，一成一败，六亲冷淡，兄弟不和，子息难靠，初年晦破，辛苦奔波，末限胜前。

**午时初**　诗：午时自有威，出入有人随，一生常受用，上马贵人接。  
解：父母双全，為人近贵，六亲兄弟有力，子息三五枝，衣禄不亏，富贵快活之命。

## 8. 科举（科名）
- 结论：三世书系（aqioo 三世书栏目全部页面、heyix 三世演禽全书目录）**没有专门的科举/科名查表**；与读书最接近的"学堂"已在 RULES.md 第4节。以下是最接近、且可机算的有来源规则，来自宋《五行精纪·论科名》（通书/命书系，非三世书，UI 需标注出处）：https://asklingxi.com/books/wuxing-jingji/20-huagai/04-keming
- 需要时柱：时干用五鼠遁（三世演禽全书"起八字例"："日上起时：甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。"）：子时天干 = 甲己日→甲，乙庚→丙，丙辛→戊，丁壬→庚，戊癸→壬，按时支顺推。时辰不详则跳过时柱条件。
- 规则（可同时命中多条）：
  1. 【科名贵】日柱或时柱 ∈ {甲辰 乙巳 丙午 丁未 戊申 己酉 庚戌 辛亥 壬子 癸丑}（甲辰旬）。原文："自甲辰至癸丑一旬，俱是在日时上，无不及第，两三位者必作前名。（广信）" 日、时都在 → 加显"两三位者必作前名"。
  2. 【魁星】日柱或时柱 ∈ {丁亥 辛卯 庚戌}。原文："丁亥辛卯庚戍 以上日时犯者，多占解省殿魁，必作前名人。（同上）"（"庚戍"=庚戌，原文错字照录。）
  3. 【又魁星】以年干五虎遁（年上起月：甲己丙作首…）求寅、巳、申、亥四位干支；月/日/时柱有其一即中（【待核】原文未写看哪几柱）。原文："寅申巳亥四位，为馆殿词林之贵，亦主学堂，大爱本年遁起四位为魁星，如癸巳人从寅上遁起甲寅，丁巳、庚申、癸亥此四位是也，又如丁卯人从寅上遁起壬寅、乙巳、戊申、辛亥四位是，馀皆凖此为例。（马子才命格）" 寅位天干：甲己年丙，乙庚戊，丙辛庚，丁壬壬，戊癸甲；巳=寅干+3，申=+6，亥=+9（天干循环）。
  4. 【一说魁星】四柱中见 甲辰 丁未 庚戌 癸丑。原文："一说云：甲辰、丁未、庚戍、癸丑四位是魁星，甲木旺于东方，丁火旺于南方，庚金旺于西方，癸水旺北方，盖取逐方旺气，加于辰戍丑未之上，以为魁星也。"
  5. 【岁窠】月柱地支 == 年柱地支。原文："岁窠者，盖以命建之月是也，谓如子生人在子，丑生人在丑，馀凖此，若生月遇之，运气相扶，主辞学丰胆，科名显赫，假令甲子人十一月是也，一云台阁杀，君子吉，小人凶。（三命指掌）"
  - 全不中：显示"本法未见科名星"即可，不另编断语（原文无）。

### 9A. 三世书禄运表（官禄强弱）：生肖 + 农历月
- 来源：表与计算方法 https://blog.wenxuecity.com/myblog/7584/200904/39536.html （该页解说只到破禄）；12条完整解说取 https://www.ezvivi.com/article/313867.asp （繁体；前7条与文学城内容相同，仅繁简之别）。
- 原文计算方法："以个人生肖，配合农历出生月份…如在立春前出生（即新历二月四日前），便算上一个年度数，月份最好根据出生节气计算…例如：农历十月出生生肖属龙…交叉点是「执禄」"。
- 公式（表12行全部符合）：k = (农历月 − 1 − 年支index) mod 12，k 0..11 = 建 除 满 平 定 执 破 危 成 收 开 闭（禄）。例：龙(4)+十月 → (10−1−4)=5 → 执禄 ✓。（原文建议也可用节气月：月数 = 寅月1…丑月12。）
- 解说（ezvivi 繁体原文）：
  - **建祿** 前世命定：建祿祿半盈、百事能謀成、門庭經書熟、定是幸福人。 現世托化：橋頭托化使帶貴、此命終身福不輕，早年作事事皆空，晚景天付萬傾田。 影響今世：現世是春風得意，利官近 貴衣食豐足、一生清閒，名利雙全、女人操持旺相之命；亦是早年發達之命。
  - **除祿** 前世命定：除祿祿難求、百計枉用心；改姓名產地、才得少許檻。 現世托化：路傍托化有刑傷，早年刑父克兒孫，一生註定孤獨身，苦心竭力也成空。 影響今世：現世是骨肉刑傷，為人勞碌手足無時停；早年財帛不聚，多收入多支出；財來財去、晚來興隆，女人稟性好靜，一生安穩有幸。
  - **滿祿** 前世命定：滿祿祿有餘、命帶無刑傷；不用身勞苦就能得世間財。 現世托化：山頭托化有靈性，利官近貴自怡然，兄弟叔侄皆無靠，一身福祿晚來隆。 影響今世：現世衣祿難為、六親少靠自立成家；少年勞碌、晚年大利。女人中年與晚年犠性利益、操持之命。
  - **平祿** 前世命定：平祿祿悠悠、無災亦無患、努力枉白費、命定是平庸。 現世托化：屋宇托化命不同，為人處事不平凡，中年衣祿瀟堂春，成家立業福無窮。 影響今世：現世心直口快，一生衣祿豐足，自然善閒遊、嬉戲不受人欺、六親有靠，妻招年長、配偶和合，長壽之命。
  - **定祿** 前世命定：定祿由天定、莫要苦中求、努力亦旺然、三生也無禍。 現世托化：樹下托化命若何，前途困苦總難免，命中刑傷兩道同，老來自有福星照。 影響今世：現在是一生近貴、百事如意、文武皆通、福祿有餘、發福發貴之命。女人是福壽無虛之命。
  - **執祿** 前世命定：執祿命多遭、困苦總難免、早年財流水、晚景難積聚。 現世托化：河邊托化最聰明，作事心中有主張，前面崎嶇也嘗過，後來必定得黃金。 影響今世：現世是性情心急、有口無心、有事難藏、易怒易好、反覆無情、父母有刑、重拜雙親、女人管夫、命硬三分、子息長孝。
  - **破祿** 前世命定：破祿福祿無、此是孤獨身、門庭雲遮月、何日見月明。 現世托化：草傍托化近貴人，技藝超群壓群雄，刻期勤勞積蓄多，福壽雙全至老年。 影響今世：現世焉人聰明伶俐、初年作事顛倒、中年財帛足用、晚景反倒難財，女人養畜如意、發福之命。
  - **危祿** 前世命定：危祿命如何、居道衣祿多、出家方為妙、一生拜佛前。 現世托化：田園托化祿有餘，家族緣薄六親疏，離祖和業方為妙，發福發貴財循來。 影響今世：現世為人誠實、一生利官近貴、家道興寧衣食足用；早年財物不聚，晚影興隆。離祖創業最宜、女人賢良、旺夫之命。
  - **成祿** 前世命定：成祿祿綿長、作事有主張；倘避風霜雨、晚景定安康。 現世托化：爐傍托兒了爭鬥，少年不宜出外鄉，中年作事獲成功，晚景更是番從前。 影響今世：現世世為衣祿不少，不若是非、夫妻無刑、兒女見遲最好，雖有衣祿財帛，但晚景會有大破耗，小心為宜。女有操持之命。
  - **收祿** 前世命定：收祿是不同、此人不平庸、中年逍遙福、晚年運大通。 現世托化：池邊托化人仁德，作事無虛心忠實，立身先苦後甘甜，老來可得滿載銀。 影響今世：現世為人心性溫和、衣祿財帛豐盈通文藝；有才華。男女有再婚、花燭重明之嫌。後來夫妻和睦、百年偕老、女人溫柔體貼之命。
  - **開祿** 前世命定：開祿最聰明、作事近貴人；衣祿天註定、悠然白豐享。 現世托化：船上托化運興隆，作事不甘居人後，青年連財難承聚，晚年發達積萬金。 影響今世：現世多學才成，衣食足用；男招好妻、身閒心苦、多喜多憂。六親冷淡、凡事自作自為、女人興旺賢能之命。
  - **閉祿** 前世命定：閉祿苦中求、何時月照命、祖基也難立、中年衣食盈。 現世托化：花旁托化得內助，作事不定多變動，先難後易苦難中，發財須五十六。 影響今世：現世為人心性寬、文武皆通，有權柄及謀略。早年平平、中年有成就、成事逢凶化吉、女人旺夫發達之命。
- 原文总评可附："前世星宿為滿祿、成祿、開祿之人前世非富即貴…建祿之人…憑藉飽讀詩書成就功名…收祿、閉祿之人前世為苦盡甘來之命…平祿、定祿之人…無禍無災地度過一生；而除祿、執祿、破祿、危祿之人前世則財少困難多"（ezvivi）。
