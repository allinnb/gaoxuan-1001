## 与搞玄线上版的关系

- **此刻课** ↔ 搞玄 `/ask/`：同为大六壬起课。未并入的：场景类别（发消息/面试谈薪/买不买/等结果/找东西）、“倾向 + 理由 + 一步行动”、三幕剧（初中末传 + 天将白话）、自定义起课时间、专业模式、式盘周边。
- **年度通胜 2027** ↔ 搞玄 `/2027/ /jiaju/ /taisui/ /fengshui/2027/`：大部分已覆盖。未并入的：春牛图、地母经、贵人方位 + 开运色数。注意：本原型“生成我的通胜”按钮实测无输出。
- **奇门择时** ↔ 搞玄 `/timing/`：择日 + 奇门时段方位已覆盖。未并入的：今日十二时辰模式卡（专注/沟通/休息/行动 + 分数）、九宫盘面 + 格局白话、推荐加分明细、避开时段、九宫盘摆件定制。

## 用途

作为安卓 App（xiào jiǎo）“问”“今日”“择”三页的交互参考；引擎实现以共享 TS 内核与金标用例为准，不直接复用这里的计算代码。
