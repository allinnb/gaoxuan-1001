# 搞玄@壹仟零壹夜 — 计算规则总表（以此为准）

所有原文解说文字在 src-*.txt 文件里，照录（可删掉"[]"、图片占位、网址）。下面是每个算法的输入与查表规则。

## 0. 通用基础
- 地支序 BR = 子丑寅卯辰巳午未申酉戌亥 (index 0..11)；天干 ST = 甲乙丙丁戊己庚辛壬癸。
- 生肖 = 鼠牛虎兔龙蛇马羊猴鸡狗猪，对应年支。
- 农历月份数字 1..12（正月=1）。闰月按本月算（闰六月=六月）。
- 时辰：23–1子，1–3丑，3–5寅 … 21–23亥。hourBranch = floor(((hour+1)%24)/2)。
- 输入：公历生日 + 出生时间（可选"时辰不详"）+ 性别。同时提供"直接输入农历"模式（农历年、月、日、是否闰月、时辰）。
- 历法数据 calendar-data.json（1899–2100，已用 lunar_python 预计算，务必内嵌进 HTML，不能联网）：
  - lunarYears[Y] = { ny: 农历正月初一的公历日期, m: [[月数字, 是否闰(1/0), 当月天数], ...按顺序] }。公历→农历：找到 ny<=日期 的最大 Y，按天数累加定位月和日。
  - jie[Y] = 当年12个"节"的公历时刻（北京时间）顺序为 小寒,立春,惊蛰,清明,立夏,芒种,小暑,立秋,白露,寒露,立冬,大雪。
  - 年柱（干支）以立春为界：出生时刻早于当年立春 → 用上一年。年干 = ST[(Y-4)%10]，年支 = BR[(Y-4)%12]（Y 为立春界定后的年份）。
  - 月柱地支（"月地支"）以节为界：立春后寅月、惊蛰后卯、清明后辰、立夏后巳、芒种后午、小暑后未、立秋后申、白露后酉、寒露后戌、立冬后亥、大雪后子、小寒后丑。
  - 日柱：1900-01-31 为 甲辰日（60甲子序号 40，甲子=0）。dayIndex = (40 + 相差天数) mod 60。23:00 后出生：显示提示"晚子时，部分流派算次日"，默认仍按当天。
  - 纳音（60甲子，每两个一组）：海中金、炉中火、大林木、路旁土、剑锋金、山头火、涧下水、城头土、白蜡金、杨柳木、泉中水、屋上土、霹雳火、松柏木、长流水、砂中金、山下火、平地木、壁上土、金箔金、覆灯火、天河水、大驿土、钗钏金、桑柘木、大溪水、沙中土、天上火、石榴木、大海水。纳音五行 = 最后一个字。
- 验证用例（必须一致）：
  - 1980-06-06 12:00 → 农历庚申年四月廿四，年柱庚申，月柱壬午（月支午），日柱庚戌，日纳音钗钏金，午时
  - 1990-01-15 08:00 → 农历己巳年十二月十九，年柱己巳，月支丑，日柱庚辰（白蜡金），辰时
  - 2025-06-30 12:00 → 农历乙巳年六月初六，月支午，日柱庚午（路旁土），午时
  - 2000-02-04 21:00 → 农历己卯年十二月廿九，但已过立春(2000-02-04 20:40) → 年柱庚辰，月支寅，日柱壬辰（长流水），亥时
  - 1964-09-10 10:00 → 农历甲辰年八月初五，日柱壬戌（大海水），巳时
- 年份说明：页面上显示"本应用年干支以立春为界"。

## 12. 小六壬（今日一问；来自《通胜锦囊》目录）
- 用"现在"的农历月、农历日、时辰（也可手动选）：index = (month + day + hourIndex(子=1…亥=12) - 3) mod 6
  0 大安 1 留连 2 速喜 3 赤口 4 小吉 5 空亡
- 诗：
  大安：大安事事昌，求财在坤方，失物去不远，宅舍保安康。行人身未动，病者主无妨，将军回田野，仔细更推详。
  留连：留连事难成，求谋日未明，官事只宜缓，去者未回程。失物南方见，急讨方称心，更须防口舌，人口且平平。
  速喜：速喜喜来临，求财向南行，失物申未午，逢人路上寻。官事有福德，病者无祸侵，田宅六畜吉，行人有信音。
  赤口：赤口主口舌，官非切宜防，失物速速讨，行人有惊慌。六畜多作怪，病者出西方，更须防咀咒，诚恐染瘟皇。
  小吉：小吉最吉昌，路上好商量，阴人来报喜，失物在坤方。行人立便至，交关甚是强，凡事皆和合，病者叩穷苍。
  空亡：空亡事不祥，阴人多乖张，求财无利益，行人有灾殃。失物寻不见，官事有刑伤，病人逢暗鬼，解禳保安康。
